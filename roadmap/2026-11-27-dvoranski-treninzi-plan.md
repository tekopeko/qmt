## What was settled (the owner's words, then the decision)

**A tab of its own** — "create a new tab called 'Dvoranski treninzi' in the same level of
hierarchy as the 'Online treninzi'"; "I would show the tab only to members with a gym
plan. Similarly how a online training tab shows only to members with an online plan.";
"for now the online users will only do trainings from their online training plan". The
tab is the members' with a running grupni, individualni, poluindividualni or
rehabilitacija plan, and staff's. Members write there; the Karton keeps the record (its
diary, each training a link into the tab); a training outside a termin is the tab's too.
The raspored's and the login prompt's shortcuts stay. A plan lapsed: the tab goes, the
records stay, and a training still open for writing stays reachable by its links.

**The hierarchy** — "A gym training consists of 'Stanica' and 'Kružni set' where the
'Kružni set' consists of 4 of 'Krug' at default which can be changed. Each 'Krug' is the
set of same exercises, but the user can edit the number of reps done after each 'Krug'
during the pause." A training is a row of blocks:

- **Stanica**: one exercise with serije, ponavljanja, opterećenje (kg), pauza, vrijeme
  (seconds, "if applicable like plank") and a comment; a tick per set, the pause counting
  down after each.
- **Kružni set**: several exercises (four rows to start, "+ vježba"), each with
  ponavljanja / opterećenje / vrijeme; a number of **Krug** ("a fixed number of 4 first
  but the user can remove a 'krug' or add 'krug' as well, the main emphasis is on the
  minimizing complications for the user"); one "Krug odrađen" per round, the pause after
  it, "No pause between exercises inside one 'Krug'"; the numbers of a round editable
  during the pause, the next round starting from them.

The named parts go: "yes, these named parts disappear for now for the gym trainings".

**Templates** — "In the start, there would be two templates. One is 'Stanični' with 6
'Stanica' in a row […] The second template is a training plan with Stanica first and then
Kružni part and the Kružni part has 4 'Krug' parts by default but can be added or
removed."; the third "Amir will create … later and give it a name". Both start empty of
exercises (the member picks the exercise and its numbers when he reaches a station; yes).
"The user will be able to add 'Stanica' and 'Kružni set' on his own as well, but it is
preferable he chooses the already made templates." What comes next is the template's next
block ("He will be able to start what comes next in the template which he starts.").

**The page** — not static: the online player's layout. The current block is the main
card; an overview lists every block (done with what was done and a ✓, the current one
with its count, an upcoming one "prazna"); a progress strip, a piece per block; a running
clock from the first tick, shown and not recorded (some will fill a training in
afterwards); the pause bar after every tick and every Krug; "Nastavi trening" opens the
next block, "Završi trening" the osvrt. Not Amir's literal pop-up windows: one page, the
current step the only thing open.

**Freedom** — blocks in any order (a tap in the overview opens one); "I want the user to
be able to insert the exercise in the next 'Stanica' block which is still empty whenever
he wants" (any empty Stanica is filled at any time); "+ Stanica" and "+ Kružni set" at
any time; one block is removed at any time (asking first while it holds a tick); the
whole template is swapped only before the first tick.

**Ticks** — "he needs to check every station he did and changing the number of sets and
reps is optional". A block holding no exercise at "Završi trening" is not recorded.

**Feedback** — "I would add the feedback of every station and every 'Kruzni set' part
even though we dont use it now, it will be useful for Amir." … "per Stanica and one per
'Kruzni set'. I dont want the user feedback for each Krug separately": one optional
rating per Stanica, one per Kružni set (asked when its last Krug is done), none per Krug.

**Amir's search** — "we will still have a search bar for Amir to search a particular user
and the exercise and see what he has done last?": yes, the Karton tab's member search
(its own change of the same day: a pick opens that member's karton) and that karton's
"Povijest vježbe". One screen for member and exercise together: later.

**Unchanged**: when a training opens and closes (4 h before the termin to the end of the
next day; staff acting as the member at any time), the osvrt, "Otvori kao član",
"Povijest vježbe", the maxes, no load next time.

**Removed**: the gym page's "Dio", "Uredi dio" and named parts; "Odaberi gotov trening"
over dvoranski programmes' days (the new templates take its place); the "Vrsta" choice
on the programme forms (no new dvoranski programme; the ones there stay staff's, to edit
or delete).
